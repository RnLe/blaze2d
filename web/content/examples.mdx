# Examples

Start with a crystal, inspect a parameter study, or extract projected operators.
Each example provides the same TOML file to the browser and native solver.
The Python snippets show how to run that file locally and access named NumPy arrays.

Browser calculations use f64 precision. Python also supports f32 and parallel
execution across configurations. See [API & TOML](/configuration) for coordinate
conventions, result dimensions, and advanced native inputs.
