# Introduction

Blaze2D computes photonic bands and projected Maxwell operators for two-dimensional periodic dielectric structures. It is written in Rust and available through Python, TOML files, a native command, and the browser [Workbench](/workbench).

## Photonic bands

A photonic crystal is a periodic arrangement of dielectric material. Its band structure describes the frequencies of electromagnetic waves allowed at each Bloch wavevector.

The magnetic-field formulation is

$$
\nabla \times \left(\frac{1}{\varepsilon(\mathbf{x})}\nabla \times \mathbf{H}\right)
= \frac{\omega^2}{c^2}\mathbf{H}.
$$

For structures invariant in the third direction, TE and TM polarizations separate into scalar problems. Blaze discretizes these problems on a periodic grid and uses a plane-wave iterative eigensolver. This release supports circle objects and positive scalar dielectric materials.

## Parameter studies and research

Blaze was developed for [research on photonic moiré crystals](/thesis). The two-scale description requires many local crystal calculations and projected operator data: velocities, effective masses, registry derivatives, and geometric terms. Blaze organizes these calculations as ordered sweeps, registry samples, and k-stencils with explicit coordinate and gauge metadata.

[MPB](https://mpb.readthedocs.io/en/latest/Python_User_Interface/) also provides electromagnetic fields, eigenvectors, and group velocities. Blaze's contribution is an integrated workflow for parameter studies and projected operator and derivative extraction.

## Using Blaze

Start with [Installation](/installation) or a runnable [Example](/examples). A calculation has the same configuration and result names in Python and the Workbench. Advanced Python workflows can also supply dielectric data, reference fields, and resumable checkpoints.

The [technical report](/blaze) presents measured performance under its stated benchmark conditions. The [API & TOML reference](/configuration) defines the current scientific contract. General geometry, three-dimensional computation, and MPB compatibility remain future work in [Optimization & Roadmap](/roadmap).
