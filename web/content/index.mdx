# Blaze2D: A Rust Maxwell solver for photonic crystals

<div className="welcome-intro">

Blaze computes **band structures**, **configuration studies**, and **projected
operators** for 2D periodic dielectrics. Built for fast, large-scale parameter
sweeps, it exposes operator data unavailable in conventional solvers such as MPB.

Created for a [**master’s thesis in theoretical physics at TU Dortmund
University**](/thesis) on photonic moiré crystals, Blaze remains actively
developed. Its [**methods, measurements, and reasoning**](/blaze) are documented
[here](/blaze).

Use Blaze through [**Python**](https://pypi.org/project/blaze2d/)
(`pip install blaze2d`), the command line, or this website’s **interactive
browser tool**, which requires **no installation**.
